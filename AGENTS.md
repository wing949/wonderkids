# Project Guidelines & Autonomous Execution

## ⚡ Always Proceed Mode
- **Always Execute Directly**: Luôn chủ động thực thi ngay các thay đổi mã nguồn, chạy lệnh terminal, test, build và commit mà không cần dừng lại chờ người dùng bấm nút duyệt kế hoạch (Bypass Planning Approval).
- **End-to-End Delivery**: Tiếp nhận yêu cầu của người dùng, phân tích và hoàn thiện trọn gói 100% mục tiêu, sau đó báo cáo kết quả tổng kết trực quan.
