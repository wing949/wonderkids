# Project Execution Policy: Always Proceed

## Autonomous Execution Rules
- **Direct Action**: Do not block on Planning Mode or request manual feedback/confirmation before executing commands, code edits, builds, or tests.
- **Proactive Implementation**: When the user gives a prompt or task, immediately research, implement the code changes, run verification tests, and report the completed results.
- **No Unnecessary Prompts**: Avoid asking trivial confirmation questions. Proceed autonomously to accomplish the user's objective end-to-end.
